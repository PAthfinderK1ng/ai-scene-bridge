# medium/ — 「场景对话」v5（场景程序）

人和 AI 沟通三维游戏场景的媒介。人只做选择、指点、判断；AI 自己搭结构：写一段**场景程序（plan v2）**——形体（盒、圆柱、锥、穹顶、拱、环、棱柱…）与建筑件（房子、塔、墙、院、台阶、平台、浮岛、水…）组成组，组可以嵌套、**重复**（一排 / 网格 / 环形 / 沿路 / 散布 / 镜像 / 叠层），地形用**雕刻操作**（抬起、压低、削平、台阶化、坡道、开沟、成湖、立崖…）组合；台地、撒房子、迷宫 / 矿道只是题材需要才用的**生成器节点**。
**局部尺寸与偏移可以写，全局摆放交给引擎**：根节点用锚点（`site.N`、`hall.top`、`towers[2]`…），组内用 `offset_m`；落地、避让、路由、检查都由确定性引擎做。
规格：`docs/06-场景程序.md`（v5 唯一规格）；空间内部布局见 `docs/04` §8；六原则见 `docs/03` §1。

## 跑起来

```bat
.venv\Scripts\python -X utf8 desktop\app.py
```
起一个只监听 127.0.0.1 的本地服务（静态文件 + `/api/*`）并开窗口；`--no-window --port 8791` 只起服务，浏览器开 http://127.0.0.1:8791/medium/ 。
没有密钥时自动用模拟 AI（不花钱）；点右上角「AI：…」选 DeepSeek 或 Claude 并填密钥。密钥只存在本机 `%LOCALAPPDATA%\ai-scene-bridge\config.json`，网页拿不到。
首屏也可以直接打开 7 段示例程序（星穹学院 / 海盗港 / 空中花园 / 沙漠神殿 / 赛博夜市 / 山城村庄 / 矿洞迷宫），本地，不调 AI。

## 四步：说 → 选 → 改 → 出

| 步 | 人做什么 | 程序 / AI 做什么 |
| --- | --- | --- |
| 说 | 一句话（首屏有示例句） | **调 AI**：先构思三个**空间组织不同**的概念，再并行展开成三段场景程序；引擎把每段编译成几何 |
| 选 | 点一张卡：概念名 + 一句话 + 关键结构 + 编译后的俯视缩略图；结构摘要里蓝色是空间组织（环形 / 垂直 / 地下 / 水上…），黄底是只有这一张才有的结构 | 不问问题，直接进「改」。三个都不要 →「重出」（调 AI） |
| 改 | 右栏场景树里拧旋钮、加 / 删 / 锁；图上拖、画、圈、剖切 | **全部本地**：程序一变就重编译，提示条说一句并给「撤销」，聊天里不写 |
| 出 | 随时可点 | 引擎包（scene.sid.json + scene.plan.json + views/*.png + BRIEF.md）；读回对比、红点三选一 |

只有三种动作调 AI（按钮带「调 AI」小标）：**发送一句话、「三个都不要，重出」、「换一批」**。说一句 = 构思 1 次 + 展开 3 次，聊天里一行写三步合计：「DeepSeek flash · 构思 + 展开 ×3 · 21.4 s · 18.2k token · ¥0.012」（模拟写「不花钱」）；出卡后一行「按你的话锁定：…」。
「改」里打字 = AI 回程序树上的 ops（`set` / `add` / `remove`，按 id 找，含 `towers[2]` 这种实例），本地应用、可撤销；锁住的项不动（点了锁住的项的名字时直说没改）。
「换一批」= 再出三个新概念；场景树里锁住的项三张都保留（服务端按 `locked` 原样放回）。

### 改：右栏「构成 · 场景树」

1. **选中**（只在点了重复里的单个实例 / 空间内部的部件 / 连接点 / 一个点时出）：实例卡有「只去掉这一个」（写进重复的 `skip`）、「回到模板」（清掉 `overrides[k]`）、剖到这里。
2. **场景树**：五组——场地与出生点 / 地形（雕刻操作一行一个）/ 场景（节点树：组 → 子节点，缩进，可收起；重复写「× 6 · 环形 · 半径 33 m」，模板是它的子行「↳ 法师塔」）/ 关系 / 外观。每行：锁 · 名字 · 关键值 · ×。点开是从 `spec/plan.schema.json` 的 `x-ui` 生成的旋钮（`knobsFor`）：尺寸（按类型的 [宽, 高, 深] / [直径, 高]）、数量、半径、间距、行列、起始方位、偏移（东 / 南）、转、离地、落地、屋顶、层数、标签、锚点（基准下拉 + 方位下拉：顶上 / 北侧 / 里面…）；数字旋钮的名字可左右拖。
   「＋ 加一个节点…」按形体 / 建筑件 / 组合 / 连接 / 生成器分组（`newElement`，根节点锚到场地中心）；组的旋钮里「＋ 加子节点…」（不写锚点，用局部偏移）；「＋ 加地形操作…」「＋ 加一条关系…」。
   点一项 = 图上高亮它生成的整组（按 `index`，重复 = 全部实例）；点图上的东西 = 树里展开对应的项（祖先组自动展开；实例点到它的重复，那一行标「#4」）。
   空间项另有「换一个」（换 `layout_seed`）、内部层切换、看地下 / 天上层、剖到这里，以及通道总长 / 房间 / 死路 / 回环 / 入口到终点。外观项：时段、气氛、色板（逐色可改、偏冷 / 偏暖 / 灰一点、风格板、参考图取色）。
3. **检查**：✗ 在前带修法（ops 修法直接改程序；引擎修法留不住几何，就记下它要忽略的，否则换一个种子重排）；全 ✓ 折成一行。

### 改：中栏

- 工具条：移动（V）/ 画路（P）/ 圈区域（R）/ 剖切（S）/ 擦除（E）· 撤销（Ctrl+Z）/ 重做（Ctrl+Shift+Z、Ctrl+Y）· 3D 小窗。视图：俯视（1）/ 剖面（2）/ 第一眼（3）/ 3D（4）。Esc：取消拖动 → 关弹窗 → 回到对比前 → 回到移动 → 取消选中；Delete 删除选中（选中的是实例就只去掉这一个）。
- **图上拖 = 改 `offset_m`**（`offsetFromPoint` 在父组坐标里反算：它是仿射的，拖动量换算成父坐标系里的偏移增量，锚点不变）：形体 / 组里的子节点 / 地形操作 / 空间 / 出生点。
  **重复里的一个实例**：直接拖 = **整个重复一起挪**（改重复的 `offset_m`）；**按住 Alt 拖 = 只挪这一个**（写进重复的 `overrides[k].offset_m`，不拆成独立节点——保持「一个重复」的结构，模板改了它也跟着变）。撒房子生成的房子拖 = 整个生成器挪。连接、传送门不能拖（改它的从 / 到）。
- 画路：从一个东西画到另一个 = 加一条连接（`link`，两头吸到最近的节点 / 实例 / 地形块 / 出生点），样式在树里改。圈区域：加树林 / 田 / 撒房子 / 水池 / 平台（锚在场地中心，偏移与尺寸取圈的范围）；在地下 / 天上层圈 = 新建空间（迷宫 / 矿道 / 厅堂 / 洞穴网 / 单室）。擦除：点掉一个节点 / 地形块 / 连接；点重复里的一个 = 只去掉这一个。
- 左侧图层条：天上 / 地面 / 地下；有多层空间时下面是内部层（入口 / 2 层 / 3 层）。
- 剖面：**悬空的形体上下拖 = 改 `elev_m`**（改带着它悬空的那个节点——浮岛上的房子拖的是浮岛；重复里的按 Alt 只改这一个）；地标顶边 = 改尺寸的高；空间底面 = 改 `depth_m`（天上改 `elev_m`）；净高；台阶化的地形 = 改它的高 / 每级高；每层高 = `site.layer_m`。拖动中节流重算，只更新 3D 小窗。

## 文件

```
medium/
  index.html  style.css
  app.js         一个 store（plan、seed、编译结果、撤销栈、选中、视图状态）+ 说 / 选 / 改 / 出 + 聊天 + 调 /api + 三张卡 + 换一批 + 图上手势（拖 = 改偏移、画 = 加连接、圈 = 加生成器 / 空间）+ 剖面手势 + 演示
  ui.js          右栏：场景树与旋钮、＋加、选中卡、检查、外观；AI 设置弹窗；导出弹窗（引擎包、BRIEF、读回对比）
  views/         map（俯视 + 图层 + 标签避让 + 手势）、profile（剖面）、eye（第一眼）、view3d（3D）——纯函数，不 import app.js / ui.js
  engine/        plan（规范化 / 编译 / ops / 旋钮）、program（场景程序解释器）、interior、terrain、layout、routing、relations、section、color、strokes、validate、sid（见 engine/SPEC.md）
  tests/flow.test.html   界面流程测试（需要本地服务）
```
模块之间直接 import 函数，没有 `initX(deps)` 注入；唯一的全局是调试用的 `window.__scene`。
v5 不再有 v4 的「人的覆盖」（拖过的单栋房子、手画的主路折点、圈的地…）：人在图上做的一切都落成程序里的偏移 / 节点，所以撤销、导出、AI 改、换一批看到的是同一份程序。

## 演示 / 截图

`/medium/?demo=cards|pick|edit`（模拟 draft「我要生成魔法学院」；pick 选第一张，edit 再把重复的数量 +1 并选中一个实例）、
`?demo=academy|harbor|sky|temple|cyber|village|maze`（直接打开对应的示例程序并编译，不调 AI；maze 选中迷宫并切到地下层）、`?demo=export`（学院 + 导出弹窗）、`?demo=plan&plan=build/eval/<卡名>`（打开评测时存下的卡，路径从仓库根算，不带 .plan.json）。
可加 `&view=profile|eye|three`（profile 会剖过主地标）、`&level=1`、`&inset=1`、`&intent=…`（cards / pick / edit 用的那句话）。

## 几条铁律

- **AI 不写全局坐标**：根节点用锚点，只有组内（和相对锚点）用局部 `offset_m`；人拖过的也只记成偏移。schema 里没有坐标字段，带了会被丢掉。
- **本地操作绝不调 AI**：`app.js` 里只有 `onIntent`（说 / 重出）、`onText`（打字）、`variants`（换一批）走 `/api/ai/*`；其它改动都经 `edit()` / `planOps()`。
- **确定性**：同 plan + seed → 同 SID；「换一个」只换 `layout_seed`。
- **锁住的不动**：`plan.locks` 里的项，AI 的 ops 与换一批都不碰。
