# medium/ — 「场景对话」v4

人和 AI 沟通三维游戏场景的媒介。人只做选择、指点、判断；AI 输出开放的**构成图（plan）**——任意数量的地形块 / 区域 / 建筑类型 / 地标 / 路 / 水 / 空间 / 关系，名字随便起，尺寸用米，位置只用相对关系，**没有坐标**；几何由确定性引擎编译。
规格：`docs/05-AI原生场景构成.md`（v4 唯一规格）；空间内部布局见 `docs/04` §8；六原则见 `docs/03` §1。

## 跑起来

```bat
.venv\Scripts\python -X utf8 desktop\app.py
```
起一个只监听 127.0.0.1 的本地服务（静态文件 + `/api/*`）并开窗口；`--no-window --port 8791` 只起服务，浏览器开 http://127.0.0.1:8791/medium/ 。
没有密钥时自动用模拟 AI（不花钱）；点右上角「AI：…」选 DeepSeek 或 Claude 并填密钥。密钥只存在本机 `%LOCALAPPDATA%\ai-scene-bridge\config.json`，网页拿不到。

## 四步：说 → 选 → 改 → 出

| 步 | 人做什么 | 程序 / AI 做什么 |
| --- | --- | --- |
| 说 | 一句话（首屏有示例句） | **调 AI 一次**，出 3 个构成不同的 plan；引擎把每个编译成几何 |
| 选 | 点一张卡（每张一句话 + 构成摘要，如「环台 5 级 · 吊脚木楼 · 寨门在西崖边上 · 矿洞迷宫 2 层」，三张有共同构成时标出不同的） | 不问问题，直接进「改」。三张都不要 → 「重出」（调 AI） |
| 改 | 右栏构成清单里拧旋钮、加 / 删 / 锁；图上拖、画、圈、剖切 | **全部本地**：plan 或覆盖一变就重编译，提示条说一句并给「撤销」，聊天里不写 |
| 出 | 随时可点 | 引擎包（scene.sid.json + scene.plan.json + views/*.png + BRIEF.md）；读回对比、红点三选一 |

只有三种动作调 AI（按钮带「调 AI」小标）：**发送一句话、「三张都不要，重出」、「换一批」**。每次调用后一行「DeepSeek flash · 1.8 s · 2.1k token · ¥0.002」（模拟写「不花钱」）；出卡后一行「按你的话锁定：…」。
「改」里打字 = AI 回 plan 的 ops（set / add / remove），本地应用、可撤销，锁住的项不动。
「换一批」按 plan 结构挑一条轴（地形组合 / 空间布局 / 地标关系，轮着来，整条轴都锁住就跳过）：AI 出三份，只取这条轴上的构成换进当前 plan，引用对不上的按「同组同位置」接上；和现在几乎一样时本地按轴挪一步（确定性）。

### 改：右栏

1. **选中**（只在点了单栋房子 / 连接点 / 通道 / 房间 / 你圈的地 / 主路 / 一个点时出）：事实 + 锁住 / 交回程序排 / 删除 / 剖到这里 / 换连接方式。
2. **构成清单**：分组折叠（地形〔含场地〕/ 区域 / 建筑 / 地标〔含入口〕/ 路 / 水 / 空间 / 关系 / 外观）。每项一行：锁 · 名字 · 关键值 · ×；点开是从 `spec/plan.schema.json` 的 `x-ui` 生成的旋钮（数字 = − 值 +，名字可左右拖；枚举 = 分段；引用 = 下拉；名字可改；房间清单与连接可增删）；每组底部「＋ 加一个…」按种类的默认值加。点一项 = 图上高亮它生成的所有东西（按 `index`）；点图上的东西 = 清单里展开对应的项。
   空间项另有：布局分段、大小、岔路、内部层数、走廊宽、净高、「换一个」（换 `layout_seed`）、内部层切换、看地下 / 天上层、剖到这里，以及通道总长 / 房间 / 死路 / 回环 / 入口到终点。
   外观项：时段、气氛、色板（逐色可改、偏冷 / 偏暖 / 灰一点、风格板、参考图取色）。
3. **关系检查**：✗ 在前带修法（plan 修法直接改 plan；引擎修法折回 plan / 覆盖，重编译后仍在）；全 ✓ 折成一行。

### 改：中栏

- 工具条：移动（V）/ 画路（P）/ 圈区域（R）/ 剖切（S）/ 擦除（E）· 撤销（Ctrl+Z）/ 重做（Ctrl+Shift+Z、Ctrl+Y）· 3D 小窗。视图：俯视（1）/ 剖面（2）/ 第一眼（3）/ 3D（4）。Esc：取消拖动 → 关弹窗 → 回到移动 → 取消选中；Delete 删除选中。
- 图上拖：地标 / 入口 → 写 `place.nudge_m`（人挪过，AI 看不到坐标）；地形块 → 改 `at.dir / at.dist`；空间 → 改 `offset_m`；房子 → 锁住的单栋（人的覆盖）；主路折点、连接点、剖切线。
- 左侧图层条：天上 / 地面 / 地下；有多层空间时下面是内部层（入口 / 2 层 / 3 层），当前层实画、其它淡画。地下 / 天上层「画路」= 给空间加一条通道，「圈区域」= 新建一个空间。
- 剖面：拖台地平台段、每层高、地标顶边、空间底面（按层数吸附）/ 净高；在剖面里选中空间 = 剖切直接过它。

## 文件（docs/05 §7：不再像微服务）

```
medium/
  index.html  style.css
  app.js         一个 store（plan、seed、编译结果、人的覆盖、撤销栈、选中、视图状态）+ 编译（compilePlan → 套覆盖）+ 说 / 选 / 改 / 出 + 聊天 + 调 /api + 换一批 + 图上手势与剖面回调 + 演示
  ui.js          右栏：构成清单与旋钮、选中卡、关系检查、外观；AI 设置弹窗；导出弹窗（引擎包、BRIEF、读回对比）
  views/         map（俯视 + 图层 + 标签避让 + 手势）、profile（剖面）、eye（第一眼）、view3d（3D）——纯函数，不 import app.js / ui.js
  engine/        plan（编译）、interior（空间内部）、terrain、layout、routing、relations、section、color、strokes、validate、sid（见 engine/SPEC.md）
  tests/flow.test.html   界面流程测试（需要本地服务）
```
模块之间直接 import 函数，没有 `initX(deps)` 注入；唯一的全局是调试用的 `window.__scene`。

人的覆盖（`store.user`，进撤销快照，重编译时叠回）：拖过 / 锁住的房子、删掉的房子 / 树（按位置）、手画的主路、修法补的支路、圈的地、圈出来的空间、手画的通道、拖过的连接点、单独调高的台地。

## 几条铁律

- **LLM 不写坐标**：plan 的 schema 里没有坐标字段；人拖过的只记成相对的微调（`nudge_m` / `offset_m` / `at`）。
- **本地操作绝不调 AI**：`app.js` 里只有 `onIntent`（说 / 重出）、`onText`（打字）、`variants`（换一批）走 `/api/ai/*`；其它改动都经 `edit()` / `planOps()`。
- **确定性**：同 plan + 覆盖 + seed → 同 SID；「换一个」只换 `layout_seed`。
- **锁住的不动**：`plan.locks` 里的项，AI 的 ops 与换一批都不碰。
