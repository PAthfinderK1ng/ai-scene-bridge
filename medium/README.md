# medium/ — 「场景对话」正式版

人和 AI 沟通三维游戏场景的媒介。人只做选择、指点、判断；AI 只做结构级决定；几何由确定性引擎算。
设计依据：`docs/03-交互设计-场景对话.md`（六原则）与本轮改版 `docs/04-改版-直接操作与多层空间.md`（说 → 选 → 改 → 出、直接操作、多层空间、自选剖切、只有打字才花钱）。

## 跑起来

```bat
.venv\Scripts\python -X utf8 desktop\sid_editor.py
```
会起一个只监听 127.0.0.1 的本地服务（静态文件 + `/api/*`）并用 WebView2 开窗口；`--no-window --port 8791` 只起服务，然后浏览器开 http://127.0.0.1:8791/medium/ 。
没有密钥时自动用模拟 AI（脚本，不花钱），整条流程照样能走；点右上角「AI：…」可选 DeepSeek 或 Claude 并填密钥。密钥只存在本机 `%LOCALAPPDATA%\ai-scene-bridge\config.json`，网页拿不到。

## 四步：说 → 选 → 改 → 出

| 步 | 人做什么 | 程序 / AI 做什么 |
| --- | --- | --- |
| 说 | 一句话（首屏有三个示例句） | **调 AI 一次**，出 3 张完整方案卡；引擎把每张算成几何 |
| 选 | 点中栏一张大图 | 不问问题，直接进「改」。三张都不要 → 「重出」（调 AI） |
| 改 | 拖、画、圈、剖切、点参数、加空间；撤销 / 重做 | **全部本地**：即时重算，中栏顶部提示条说一句并给「撤销」（几秒后自己收起；换视图、开弹窗时立即收起，撤销一直在工具栏），聊天里什么都不写 |
| 出 | 随时可点 | 导出引擎包（scene.sid.json + views/*.png + BRIEF.md）；读回对比、红点三选一 |

出卡后聊天里一行灰字「按你的话锁定：夜里、水车、有溪（三张都照办）」（服务端 constraints；AI 没照办被改回时加「AI 有 N 处没照办，已改回」）。顶栏只有标题、四步、AI 服务商。

只有三种动作调 AI，按钮上都有「调 AI」小标：**发送输入框的一句话、「三张都不要，重出」、「换一批」**。每次调用后聊天里一行：「DeepSeek flash · 1.8 s · 2.1k token · ¥0.002」（模拟写「不花钱」）。

### 改：中栏

- 工具条：移动（默认，V）/ 画路（P）/ 圈区域（R）/ 剖切（S）/ 擦除（E）· 撤销（Ctrl+Z）/ 重做（Ctrl+Shift+Z、Ctrl+Y）· 3D 小窗。画图工具只在俯视图出（剖面 / 第一眼 / 3D 里只留撤销、重做）。
- 视图：俯视（1）/ 剖面（2）/ 第一眼（3）/ 3D（4）。Esc 依次：取消正在进行的拖动（图回原位、不入撤销栈）→ 关弹窗 → 回到移动 → 取消选中；Delete 删除选中（任何房子都能删）。
- 俯视图左侧图层条：天上 / 地面 / 地下。当前层画实，其它层淡显；在地下 / 天上层「圈区域」= 新建一个该层的空间。
- 移动工具下可直接拖：地标、入口、房子（锁在新位置）、主路白色折点、剖切线两端与中段、空间、连接点。
- 剖切线与宽度带在俯视图上常显（沿主路时淡色），把手只在移动 / 剖切工具下出现。
- 剖面：上下拖台地平台段（只改这一层）、顶部「每层高」、地标顶边、空间整体 / 上边，拖动中 3D 实时跟随（在场景副本上算，约 10 ms 一次，节流 120 ms，不入撤销栈）；点一下 = 选中；沿主路 / 直线、宽度（拖滑块时只动带，松手才提交）、转 15°、坡度 缓 3 / 中 4 / 陡 5（按区间永远亮一档：≤ 3.4 缓、≤ 4.4 中、再高陡；确切米数在悬停提示里；不是整档时点亮着的那档回到整档，与参数面板同一规则）。
- 3D 小窗：俯视图里是可拖的浮窗（人没拖过时自己挑角：左上 → 左下 → 右下 → 右上里挡选中描边 / 剖切把手 / 地标 / 入口最少的那个，现在的角不挡就不动；拖过就记在本机、不再自动挪；镜头对准村子本身；出弹窗时隐藏；「—」收成「3D」小按钮、「×」关掉；图上拖 / 画 / 圈 / 剖切时淡到 15% 且不挡指针）；剖面里嵌在剖面下方；第一眼 / 3D 视图里不出、按钮置灰。

### 改：右栏

1. **参数**：顶部是 AI 的理解摘要（卡的 one_liner）；每个结构参数一行分段按钮（原型、层数、每层高、台地宽、地标、位置〔顶层 / 脊尽头 / 临崖 / 村口〕、入口、时段、溪），点了本地重算；没动过的带「默认」；右侧的锁 = 「换一批」与 AI 都不改它。
2. **空间层**：天上 / 地面 / 地下三组，列出空间与连接方式；＋地下空间 / ＋空中平台（锚在地标）。点条目 = 选中并切到那一层。
3. **选中**：点了什么就显示它的事实与可改项（房子：层、尺寸、朝向、锁住 / 解锁〔拖过的留在原地；程序摆的交回程序排〕、删除（程序摆的也能删，重算后那里不再长出来）；空间：种类、净高、底面、连接方式、删除；台地：高度 ± 与恢复；主路：走法……）。房子、地标、空间都有「剖到这里」：剖切改成直线、过它中心、保持当前角度、宽度至少盖住它，并切到剖面；在剖面里从空间层选中一个空间也自动这样做。没选中时隐藏。
4. **关系检查**：全 ✓ 折成一行；✗ 带修法（本地执行，可撤销）。
5. **色板**：参考图取色 / 风格板 / 冷暖微调。

## 演示 / 截图

`/medium/?demo=cards|pick|edit|drag|section|strata|export`（可加 `&view=profile|eye|three`），一律走模拟 AI。
依次：说 → 选第一张 → 点参数（层数 6、清晨）并选中一栋房子 → 拖一栋房子、拖主路折点 → 剖面把第 3 层拖高 2 m、切直线剖切并转 30° → 加地下溶洞与空中平台、切到地下层、开 3D 小窗 → 出。

## 几条铁律（代码里怎么体现）

- **LLM 永远不写坐标**：AI 只能返回 schema 里的结构字段（含 `levels` 的 anchor / 层数 / 大小）；坐标、高度、多边形、连接点全部由 `engine/*` 算。
- **本地操作绝不调 AI**：`app.js` 里只有 `onIntent`（说 / 重出）、`onText`（打字）、`variants`（换一批）会走 `/api/ai/*`；其它改动都经 `edit()`。
- **人的覆盖永远保留**：手画的路、圈的区域、拖过的地标 / 入口 / 房子 / 连接点、单独调过的台地与空间都记在 `scene.user` 或 sid 里人的对象上，重算时叠回。
- **锁住的 AI 不改**：`params.stripLocked` 剥掉 AI patch 里锁住的字段，`params.enforce` 让换一批的三张守住锁。
- **关系是算出来的**：`relations.analyze` 与 `strata.spaceChecks` 给出检查与修法。
