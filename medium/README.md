# medium/ — 「场景对话」v5（场景程序）+ v6（加到对话 / 场景会话 / 用户记忆 / 随意调高度）

人和 AI 沟通三维游戏场景的媒介。人只做选择、指点、判断；AI 自己搭结构：写一段**场景程序（plan v2）**——形体（盒、圆柱、锥、穹顶、拱、环、棱柱…）与建筑件（房子、塔、墙、院、台阶、平台、浮岛、水…）组成组，组可以嵌套、**重复**（一排 / 网格 / 环形 / 沿路 / 散布 / 镜像 / 叠层），地形用**雕刻操作**（抬起、压低、削平、台阶化、坡道、开沟、成湖、立崖…）组合；台地、撒房子、迷宫 / 矿道只是题材需要才用的**生成器节点**。
**局部尺寸与偏移可以写，全局摆放交给引擎**：根节点用锚点（`site.N`、`hall.top`、`towers[2]`…），组内用 `offset_m`；落地、避让、路由、检查都由确定性引擎做。
规格：`docs/06-场景程序.md`（v5）、`docs/07-加到对话-场景会话-用户记忆.md`（v6）；空间内部布局见 `docs/04` §8；六原则见 `docs/03` §1。

## 跑起来

```bat
.venv\Scripts\python -X utf8 desktop\app.py
```
起一个只监听 127.0.0.1 的本地服务（静态文件 + `/api/*`）并开窗口；`--no-window --port 8791` 只起服务，浏览器开 http://127.0.0.1:8791/medium/ 。
没有密钥时自动用模拟 AI（不花钱）；点右上角「AI：…」选 DeepSeek 或 Claude 并填密钥。密钥只存在本机 `%LOCALAPPDATA%\ai-scene-bridge\config.json`，网页拿不到。
首屏也可以直接打开 7 段示例程序（星穹学院 / 海盗港 / 空中花园 / 沙漠神殿 / 赛博夜市 / 山城村庄 / 矿洞迷宫），本地，不调 AI。

## 四步：说 → 选 → 改 → 出

| 步 | 人做什么 | 程序 / AI 做什么 |
| --- | --- | --- |
| 说 | 一句话（首屏有示例句） | **调 AI**：先构思三个**空间组织不同**的概念，再并行展开成三段场景程序；引擎把每段编译成几何 |
| 选 | 点一张卡：概念名 + 一句话 + 关键结构 + 编译后的俯视缩略图；结构摘要里蓝色是空间组织（环形 / 垂直 / 地下 / 水上…），黄底是只有这一张才有的结构 | 不问问题，直接进「改」。三个都不要 →「重出」（调 AI） |
| 改 | 右栏场景树里拧旋钮、加 / 删 / 锁；图上拖、画、圈、剖切 | **全部本地**：程序一变就重编译，提示条说一句并给「撤销」，聊天里不写 |
| 出 | 随时可点 | 引擎包（scene.sid.json + scene.plan.json + views/*.png + BRIEF.md）；读回对比、红点三选一 |

只有三种动作调 AI（按钮带「调 AI」小标）：**发送一句话、「三个都不要，重出」、「换一批」**。说一句 = 构思 1 次 + 展开 3 次，聊天里一行写三步合计：「DeepSeek flash · 构思 + 展开 ×3 · 21.4 s · 18.2k token · ¥0.012」（模拟写「不花钱」）；出卡后一行「按你的话锁定：…」。
「改」里打字 = AI 回程序树上的 ops（`set` / `add` / `remove`，按 id 找，含 `towers[2]` 这种实例），本地应用、可撤销；锁住的项不动（点了锁住的项的名字时直说没改）。
「换一批」= 再出三个新概念；场景树里锁住的项三张都保留（服务端按 `locked` 原样放回）。

### 改：右栏「构成 · 场景树」

1. **选中**（只在点了重复里的单个实例 / 空间内部的部件 / 连接点 / 一个点时出）：实例卡有「只去掉这一个」（写进重复的 `skip`）、「回到模板」（清掉 `overrides[k]`）、剖到这里。
2. **场景树**：五组——场地与出生点 / 地形（雕刻操作一行一个）/ 场景（节点树：组 → 子节点，缩进，可收起；重复写「× 6 · 环形 · 半径 33 m」，模板是它的子行「↳ 法师塔」）/ 关系 / 外观。每行：锁 · 名字 · 关键值 · ×。点开是从 `spec/plan.schema.json` 的 `x-ui` 生成的旋钮（`knobsFor`）：尺寸（按类型的 [宽, 高, 深] / [直径, 高]）、数量、半径、间距、行列、起始方位、偏移（东 / 南）、转、离地、落地、屋顶、层数、标签、锚点（基准下拉 + 方位下拉：顶上 / 北侧 / 里面…）；数字旋钮的名字可左右拖。
   「＋ 加一个节点…」按形体 / 建筑件 / 组合 / 连接 / 生成器分组（`newElement`，根节点锚到场地中心）；组的旋钮里「＋ 加子节点…」（不写锚点，用局部偏移）；「＋ 加地形操作…」「＋ 加一条关系…」。
   点一项 = 图上高亮它生成的整组（按 `index`，重复 = 全部实例）；点图上的东西 = 树里展开对应的项（祖先组自动展开；实例点到它的重复，那一行标「#4」）。
   空间项另有「换一个」（换 `layout_seed`）、内部层切换、看地下 / 天上层、剖到这里，以及通道总长 / 房间 / 死路 / 回环 / 入口到终点。外观项：时段、气氛、色板（逐色可改、偏冷 / 偏暖 / 灰一点、风格板、参考图取色）。
3. **检查**：✗ 在前带修法（ops 修法直接改程序；引擎修法留不住几何，就记下它要忽略的，否则换一个种子重排）；全 ✓ 折成一行。

### 改：中栏

- 工具条：移动（V）/ 画路（P）/ 圈区域（R）/ 高度（H）/ 剖切（S）/ 擦除（E）· 撤销（Ctrl+Z）/ 重做（Ctrl+Shift+Z、Ctrl+Y）· 3D 小窗。视图：俯视（1）/ 剖面（2）/ 第一眼（3）/ 3D（4）。Esc：取消拖动 → 关弹窗 → 回到对比前 → 回到移动 → 取消选中；Delete 删除选中（选中的是实例就只去掉这一个）。
- **图上拖 = 改 `offset_m`**（`offsetFromPoint` 在父组坐标里反算：它是仿射的，拖动量换算成父坐标系里的偏移增量，锚点不变）：形体 / 组里的子节点 / 地形操作 / 空间 / 出生点。
  **重复里的一个实例**：直接拖 = **整个重复一起挪**（改重复的 `offset_m`）；**按住 Alt 拖 = 只挪这一个**（写进重复的 `overrides[k].offset_m`，不拆成独立节点——保持「一个重复」的结构，模板改了它也跟着变）。撒房子生成的房子拖 = 整个生成器挪。连接、传送门不能拖（改它的从 / 到）。
- 画路：画一笔 → 弹「加到对话」（变成手绘线标记）/「直接连起来」（加一条连接 `link`，两头吸到最近的节点 / 实例 / 地形块 / 出生点）。圈区域（地面）：**变成一个圈选标记并自动加到对话**，弹窗只剩「已加到对话，说说这块要做成什么」+「清空这块里的东西」「算了」，输入框聚焦（占位「这块要做成什么？」）——不再给固定菜单；在地下 / 天上层圈 = 新建空间（迷宫 / 矿道 / 厅堂 / 洞穴网 / 单室）。擦除：点掉一个节点 / 地形块 / 连接 / 标记；点重复里的一个 = 只去掉这一个。
- **高度**（H，docs/07 §4）：在地面任意一点按下、上下拖 = 抬高 / 压低（每 px 0.1 m，吸附 0.5 m；图上显示笔刷圈与「+4.5 m」，3D 小窗实时变——拖动中用临时编译预览、节流 120 ms、不入撤销栈，松手才提交一步）；滚轮或 `[` `]` 调半径（默认 12 m）；Shift = 削平到按下点的高度（`flatten` + `target: "at_point"`）；Alt = 只压低。松手 = 在那儿放一个图钉标记 + 一个人给的地形操作 `{ op, at: <图钉>, shape: circle, size_m: [2r, 2r], height_m | depth_m, edge: slope }`，名字「手调高度 N」（AI 下一轮能看到、能引用）；按在已有图钉上再拖 = 改同一个操作。提交后自动选中它：俯视图上中心把手（拖 = 挪：手调的挪图钉，AI 的改 `offset_m`）与高度把手（上下拖 = 改 `height_m` / `depth_m`）。
- 图钉：右键 → 菜单「把 … 加到对话」「在这放个图钉」「在这调高度」；Ctrl+点：空地 = 放图钉并加到对话，点在东西上 = 把它加到对话。标记（圈选 / 手绘线 / 图钉）在图上画成虚线 / 水滴，可拖、选中后 × 删、改名（右栏选中卡与场景树「标记」组）；删图钉连同它上面的手调高度。
- 左侧图层条：天上 / 地面 / 地下；有多层空间时下面是内部层（入口 / 2 层 / 3 层）。
- 剖面：**悬空的形体上下拖 = 改 `elev_m`**（改带着它悬空的那个节点——浮岛上的房子拖的是浮岛；重复里的按 Alt 只改这一个）；地标顶边 = 改尺寸的高；空间底面 = 改 `depth_m`（天上改 `elev_m`）；净高；台阶化的地形 = 改它的高 / 每级高；每层高 = `site.layer_m`。**地面线任意一点上下拖** = 在剖切线上那个位置做同样的手调高度（Shift 削平、Alt 只压低，同一处再拖接着改）；选中的地形操作在剖面上有高度把手。拖动中节流重算，只更新 3D 小窗。

### 加到对话（docs/07 §1）

任何东西都可以加到对话：选中卡与场景树每行「＋对话」（或把那一行拖进输入框）、图上右键、圈区域 / 画路 / 图钉、输入框里打 `@` 补全名字（↑↓ 选、回车 / Tab 选中）。加进去的在输入框上方显示成**引用卡片**（种类 · 名字 · 一句事实，例「圈选 1 · 42×40 m · 地面 +0 m · 含 夜市、灯柱」；悬停看全部 facts），可单个去掉、可钉住（发完不清空）。
发送时 revise 请求多带：`refs`（每张卡用 engine `describeRef` 重新算的 `{kind, id, instance?, label, facts}`）、`history`（当前场景最近 10 轮：你的原话 + 引用名、AI 的复述 + ops 数 + effect；两次说话之间你在图上的本地改动合成一条「（我在图上改了：…）」；你那条带 `refs`（指的 id），AI 那条带 `ids`（动了的 id））、`scene_id`。
这句没加引用、又是接着说的（「还是太空了」「再密一点」「这里…」）：把上一轮的引用带上（`carried: true`，事实重新算），AI 才知道还是那一块；不是接着说的就不带。
AI 改完前端用 engine `diffCompiled(before, after)` 算**改动摘要**，聊天里写「改了：法师塔 × 6 → × 8，半径 33 → 40 m」；几乎没有看得见的变化时写「这次没有看得见的变化：可以换个说法，或者圈一块 / 右键加到对话指给我看」，并写进 history 的 effect（下一句「还是没改」时 AI 据此换改法）。没改定义、被别人长大挤走的节点单列在最前面：「顺带被挤动：第五层环廊 3 m（往北）；改了：…」。
引擎兜两件事：锚在圈选里的直线 / 网格 / 放射重复排不下 → 缩间距 / 半径（缩到挨着还放不下就少放几个），记进 `facts.plan.autofix`（fit_area）；避让时撞上的是自己子孙里的一小件、或自己的环带，最多按那一件 / 带宽推，同心的一层层环廊不会被推散（推不开就报告重叠）。
夜里（time_of_day = night）3D 里灯 / 灯笼 / 火这些小件自己发光（细高灯柱在顶上点一盏）。

### 场景会话与记忆（docs/07 §2 §3，`session.js`）

- 顶栏左上「☰ 场景名」打开左侧场景栏：每个场景 = 名字（还叫「场景 N」时自动换成程序名）、缩略图（小俯视图 SVG）、修改时间；「＋ 新场景」、改名、复制、删除（确认，进回收站 7 天，提示条可「恢复」）。每个场景存：程序 + 种子、三张候选、聊天记录（含引用小标与改动摘要）、给 AI 的历史、撤销栈（最近 30 步）、钉住的引用、视图状态。改动后 1.5 s 防抖自动保存到 `/api/scenes`（一直在改也至少 10 s 存一次；调 AI 前没存过就先存，请求才带得上 `scene_id`）；启动打开上次的场景。本地服务不可用时退回 localStorage（同样的路由，`localApi`）并提示一次。
- 顶栏「记忆 N」打开记忆面板：列表、开关、改文字 / 分类（喜欢 / 不喜欢 / 规则 / 事实）、删除、来源（你说的 / AI 建议的）、用过几次；「清空…」要确认。聊天里每条消息旁「记住这个」；你说「记住：… / 以后都… / 我不喜欢…」服务端本地存、回「记住了：…」；AI 的 `memory_suggestions` 显示成「要记住吗：… [记住] [不用]」（跟着原有调用回来，不额外调 AI）；用量那行写「用了 N 条偏好」。

## 文件

```
medium/
  index.html  style.css
  app.js         一个 store（plan、seed、编译结果、撤销栈、选中、视图状态、引用、聊天 / 历史）+ 说 / 选 / 改 / 出 + 聊天 + 调 /api + 三张卡 + 换一批 + 图上手势（拖 = 改偏移、画 / 圈 / 点 = 标记并加到对话、高度工具、地形操作把手）+ 剖面手势 + 改动摘要 + 场景的存 / 取（sceneData / loadState）+ 演示
  ui.js          右栏：场景树与旋钮、＋加、标记组、选中卡、检查、外观；引用卡片与 @ 补全（加到对话）；AI 设置弹窗；导出弹窗（引擎包、BRIEF、读回对比）
  session.js     场景会话与记忆：/api/scenes、/api/memory（服务不可用退回 localStorage）、自动保存、左侧场景栏、记忆面板、「要记住吗」
  views/         map（俯视 + 图层 + 标签避让 + 手势）、profile（剖面）、eye（第一眼）、view3d（3D）——纯函数，不 import app.js / ui.js
  engine/        plan（规范化 / 编译 / ops / 旋钮）、program（场景程序解释器）、interior、terrain、layout、routing、relations、section、color、strokes、validate、sid（见 engine/SPEC.md）
  tests/flow.test.html   界面流程测试（需要本地服务）
```
模块之间直接 import 函数，没有 `initX(deps)` 注入；唯一的全局是调试用的 `window.__scene`。
v5 不再有 v4 的「人的覆盖」（拖过的单栋房子、手画的主路折点、圈的地…）：人在图上做的一切都落成程序里的偏移 / 节点，所以撤销、导出、AI 改、换一批看到的是同一份程序。

## 演示 / 截图

`/medium/?demo=cards|pick|edit`（模拟 draft「我要生成魔法学院」；pick 选第一张，edit 再把重复的数量 +1 并选中一个实例）、
`?demo=refs`（星穹学院里圈一块 → 加到对话 → 模拟「这里做成夜市」→「还是太空了」，聊天里有改动摘要）、`?demo=height`（俯视图「高度」工具在一点拖 +6 m，选中它看把手；`&view=profile` 剖过那一处）、`?demo=scenes`（两个场景，打开场景栏停在第一个）、`?demo=memory`（两条记忆 + 记忆面板）——演示的场景与记忆都存在浏览器里的 `demo:` 前缀下（每次清空），不碰真实数据；加 `&store=server` 才走本地服务（测试用，服务要用 `SCENE_DIALOG_DATA_DIR` 指到临时目录）。
`?demo=academy|harbor|sky|temple|cyber|village|maze`（直接打开对应的示例程序并编译，不调 AI；maze 选中迷宫并切到地下层）、`?demo=export`（学院 + 导出弹窗）、`?demo=plan&plan=build/eval/<卡名>`（打开评测时存下的卡，路径从仓库根算，不带 .plan.json）。
可加 `&view=profile|eye|three`（profile 会剖过主地标）、`&level=1`、`&inset=1`、`&intent=…`（cards / pick / edit 用的那句话）。

## 几条铁律

- **AI 不写全局坐标**：根节点用锚点，只有组内（和相对锚点）用局部 `offset_m`；人拖过的也只记成偏移。schema 里没有坐标字段，带了会被丢掉。
- **本地操作绝不调 AI**：`app.js` 里只有 `onIntent`（说 / 重出）、`onText`（打字）、`variants`（换一批）走 `/api/ai/*`；其它改动都经 `edit()` / `planOps()`。引用、标记、高度、场景、记忆都是本地的，记忆建议跟着原有调用回来。
- **人画的几何人给坐标**：圈选 / 手绘线 / 图钉存在 `plan.marks`（相对场地中心，x 东 z 南，米），AI 只引用 id（`at` / `area` / `along`）。
- **确定性**：同 plan + seed → 同 SID；「换一个」只换 `layout_seed`。
- **锁住的不动**：`plan.locks` 里的项，AI 的 ops 与换一批都不碰。
