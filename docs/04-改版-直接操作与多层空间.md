> 2026-10-19，用户试用正式版后提出：右边点一下左边就给 AI 发东西（烧钱、交互差）；剖面能直接调高度、能自己选剖切线 / 宽度 / 角度；俯视图上的东西能直接拖；要能设计地下与天上的空间；带着这些简化流程；用 DeepSeek 实测。

## 2. 新流程：说 → 选 → 改 → 出

1. **说**：一句话。调 AI 一次，出三张卡（中栏并排、可点大图选）。
2. **选**：点一张。不问问题，直接进「改」。
3. **改**（全部本地、即时、可撤销）：
   - 中栏：俯视图 / 剖面 / 第一眼 / 3D 四个视图；俯视图与剖面右下角有「3D 小窗」，改什么都实时跟着变。
   - 右栏：**参数**（AI 的理解摘要 + 分段按钮 + 锁）、**空间层**（地面 / 地下 / 天上 的空间列表，＋地下空间、＋空中平台）、**选中**（点了什么就显示它的事实与可改项）、**关系检查**（折叠）、**色板**。
   - 聊天：只用来对 AI 说话（「再陡一点」「加一个地宫」）。本地操作不写进聊天，改动在中栏顶部的提示条里说一句并给「撤销」。
4. **出**：随时可点。导出包、读回对比与以前相同，BRIEF 里多了空间层与连接点。

## 3. 直接操作

### 3.1 俯视图（默认工具「移动」）

| 拖什么 | 结果 |
| --- | --- |
| 地标、入口 | 同以前的图钉：主路重接、朝向重算 |
| 房子 | 移到新位置并锁住（id 改为 `u_house_<n>`，以后重排不动它）；落在台地外 / 压路会在「关系检查」里报 |
| 主路折点 | 主路变成「你画的」，只动这一个折点 |
| 剖切线端点 / 中段 | 改剖切线的位置与角度（端点拖动时 15° 吸附，按住 Alt 不吸附） |
| 空间（当前层是地下 / 天上时） | 整体平移 |
| 连接点 | 平移（仍连接原来的两层） |

工具：移动（默认）/ 画路 / 圈区域 / 剖切（在图上拉一条线）/ 擦除；撤销 / 重做。图钉工具并入「移动」。
图层切换：俯视图左侧竖排「天上 / 地面 / 地下」。当前层画实，其它层淡显；在地下 / 天上层「圈区域」= 新建一个该层的空间（弹出种类选择）。

### 3.2 剖面

- 剖切方式：**沿主路**（默认）或 **直线**（在俯视图用「剖切」工具拉一条线，或拖已有剖切线）。宽度滑块 2–60 m：宽度带内的房子、地标、空间、连接点都投影到剖面上。俯视图上画出剖切线与宽度带。
- 直接拖：
  - 某层台地的平台段上下拖 → 只改这一层台地的高度（0.5 m 吸附，拖动时显示「第 3 层：+8.5 m」）；单独调过的层带「已单独调」标记，可「恢复」。
  - 顶部的「每层高」把手上下拖 → 改全局层高（等价于参数里的坡度）。
  - 地标顶边上下拖 → 地标高度。
  - 空间（地下 / 天上）整体上下拖 → 改底面高度；拖它的上边 → 改净高。
- 拖动过程中 3D 小窗实时跟随。

### 3.3 3D

- 「3D 小窗」：中栏右下角 320×220 可开关，跟随场景重建（节流 150 ms）；拖剖切线时显示一个半透明剖切面。
- 3D 视图里：地下空间是半透明暗色体块、地面可调透明度（切到「地下」层时自动 35%）；空中平台是带厚度的板；连接点是竖向的楼梯 / 井 / 梯子符号。

## 4. 多层空间（D18）的数据与生成

### 4.1 SID 增补（schema v0.3）

```json
"spaces": [
  { "id": "space_cave_1", "stratum": "underground", "kind": "cave",
    "polygon": [[x,z], ...], "floor_y": -9, "height": 6,
    "label": "地下溶洞", "anchor": "landmark", "generated": true }
],
"markers": [
  { "id": "conn_space_cave_1", "kind": "connector", "via": "stairs",
    "from": "ground", "to": "space_cave_1",
    "position": [x, y_bottom, z], "top_y": 12, "bottom_y": -9, "label": "下行石阶" }
],
"meta": { "section": { "mode": "trail" | "line", "line": [[x,z],[x,z]], "width_m": 12 } }
```
- `stratum`：`underground` | `sky`。`kind`：地下 `cave` 溶洞 / `tunnel` 地道 / `cellar` 地窖 / `crypt` 地宫；空中 `platform` 平台 / `walkway` 栈道 / `island` 浮岛 / `bridge` 天桥。
- `floor_y` 是可走地面的绝对高度（米）；`height` 是净高（地下）或上方可用高度（空中，平台板厚固定 1 m 在板面之下）。
- 连接点是 `markers[]` 里 `kind: "connector"`：`via` ∈ `stairs | ladder | well | shaft | elevator | rope_bridge | ramp`，`from` / `to` 是空间 id 或 `"ground"`，`position` 是下端，`top_y` / `bottom_y` 是两端高度。
- 台地单独调高：`terrain.features[].height` 写入实际值并带 `user_height: true`。

### 4.2 AI 卡片增补

Card 新增可选 `levels`（最多 3 项）：
```json
{ "stratum": "underground", "kind": "cave", "anchor": "landmark", "depth_layers": 2,
  "size": "medium", "connect": "stairs", "label": "寺下溶洞" }
{ "stratum": "sky", "kind": "walkway", "anchor": "ridge_end", "height_layers": 3,
  "size": "small", "connect": "ladder", "label": "崖顶栈道" }
```
`anchor` ∈ `landmark | village | top | plaza | ridge_end | cliff_edge | entry`；`size` ∈ `small | medium | large`。**AI 仍然不写坐标**，引擎按 anchor / 层数 / 大小生成多边形、高度与连接点。

### 4.3 引擎规则（engine/strata.js）

- 多边形：以 anchor 点为中心的圆角多边形（small 10 m / medium 18 m / large 28 m 直径，栈道 / 天桥为沿等高线或跨谷的长条），夹在 bounds 内。
- 高度：地下 `floor_y = anchor 处地面高 − depth_layers × 层高 − 净高`，保证顶板到地面 ≥ 2 m 岩层；空中 `floor_y = anchor 处地面高 + height_layers × 层高`。
- 连接点：地下空间 → 在空间多边形内、离主路最近的地面点放一个向下的连接点；空中空间 → 在 anchor 附近地面（或地标旁）放一个向上的连接点；天桥两端各一个。
- 检查（追加到关系检查）：`spaces_connected`（每个空间至少一个连接点通到地面或已连通的空间）、`spaces_clear_of_terrain`（地下顶板在整个多边形内低于地面至少 2 m；空中板底高于地面至少 3 m）。
- 人在地下 / 天上层圈的空间：`user_set: true`，重算时保留；连接点自动补一个，可拖。

## 5. 剖切（D19）的引擎接口（engine/section.js）

```js
defaultSection(sid, T) → { mode: "trail", line: [[x,z],[x,z]], width_m: 12 }
sectionPath(section, sid) → [[x,z], ...]                  // trail 模式取主路折线，line 模式取两点
sampleSection(sid, T, section) → {
  path, length_m,
  ground: [{ d, h, x, z, terrace_id, level }],          // 每 1 m
  terraces: [{ id, level, height, d0, d1, user_height }], // 剖切线穿过的台地平台段（拖动用）
  volumes: [{ id, kind, importance, d0, d1, y0, y1, label }],  // 带内体块投影
  spaces: [{ id, stratum, kind, d0, d1, floor_y, height, label }],
  connectors: [{ id, via, d, top_y, bottom_y }],
  paths: [{ id, kind, d }]                               // 与剖切线相交的路 / 溪
}
```
投影：点到剖切折线的最近点给出 `d`（弧长）与横向距离，横向距离 ≤ width/2 的才入带；体块按四角投影取 `[d0, d1]`。

## 6. 服务商（DeepSeek）

- 官方 OpenAI 兼容接口 `https://api.deepseek.com/chat/completions`，模型 `deepseek-flash`（本机密钥可用：`deepseek-flash`、`deepseek-v4-pro`）。
- `response_format: {"type": "json_object"}` + 提示词里给出字段说明与一张示例卡；`thinking: {"type": "disabled"}`（实测开着思考时 400 token 全花在推理、没出答案；关掉 1.2 s 出结果）。
- 回来后用 `schema_lite` 本地校验 + 夹取；不合格时带着错误信息重试一次。JSON 解析失败先本地修（去围栏 / 尾逗号、转义字符串里的英文双引号与换行），修好且合 schema 就不再回喂（`usage.repaired = true`，省一次调用）。
- 记录 `usage`（含 `prompt_cache_hit_tokens`），按 DeepSeek 价目估算人民币费用，显示在聊天底部。
- 配置：`%LOCALAPPDATA%\ai-scene-bridge\config.json` 的 `provider` 与 `providers.{anthropic,deepseek}`；设置弹窗可切换服务商、模型、思考开关。

## 7. 验收后的补丁（2026-10-19 晚）

- **房子落位**：关系检查加「房子 都在台地上」（含人拖过的房子，修法「挪回最近的台地」/「不重要」）；人拖过的房子压路时修法是「挪开一点」（挪到最近的空位，不删）；主路为躲开人放的房子绕路时，检查文案提一句。
- **窄带有房**：溪谷 / 环台的台地带宽保证 ≥ 8 m（放不下时 ≥ 7 m）；窄带一栋都放不下时沿带的中线再放最小的房子。3 种原型 × 窄 / 中 / 宽 × 3 / 5 / 7 层，密度 1 时每张 ≥ 6 栋、每层（广场层除外）≥ 1 栋。
- **村口**：地标位置多一个 `entry`（村口：最低一层靠入口、离入口山脚 8–12 m 的平地）。「村口 / 寨口 / 入口处」本地锁定成 entry；「从村口进」不算。
- **删房持久**：删掉的程序生成房子 / 树重算后不再长回来（按位置记），可撤销。
- **3D 实时预览**：`scene.previewState(mutator)` 给拖动中的 3D 小窗用，常见规模一次约 10 ms，大场景约 60 ms。
