怎么用

  • 选中：点对象。W / E / R 切换移动 / 旋转 / 缩放，拖 gizmo；移动吸附到网格（场景面板的「网格 m」，默认 0.5 m），缩放吸附 0.5 m，旋转吸附 5°。区域 / 路径 / 山丘只能移动，标记不能缩放。
  • 视角：鼠标左键旋转、右键平移、滚轮缩放；T 俯视 / 透视；F 全景；L 标签。
  • 添加：工具栏按钮在视角中心放一个新对象；画路径后在地面点击加点，双击或回车结束。
  • 属性：右侧面板改数字、种类、标签、颜色角色、备注；改完按回车或点别处生效。
  • 导出实验包：zip 里是 scene.sid.json、views/top.png（俯视）、views/iso.png（鸟瞰透视）、scene.glb、PROTOCOL.md、导入过的素材 assets/，解压后整个目录交给 AI。
  • 约定：单位米，+Y 上，北 = −Z（俯视图上方），位置是底面中心，rotation_y 0 = 朝北、逆时针为正。
  • Ctrl+Z / Ctrl+Y 撤销重做，Delete 删除，Esc 取消选择 / 取消画路径。
