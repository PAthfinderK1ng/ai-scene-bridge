# ai-scene-bridge

让用户和 AI 高效沟通「三维场景」的中间层工具 —— 探索项目。

## 一句话

AI（Claude Code / Cursor + UE/Unity MCP）会写代码，但不会「搭地图」。本项目探索做一个小工具：
用户在里面直接操作三维空间（摆体块、画区域、标语义、取色 / 贴参考图），导出一份 AI 能读懂的结构化描述，再由 AI 在 **Unreal Engine** 或 **Unity** 中落地。

## 出发点：四个痛点假设

| 编号 | 痛点 | 一句话 |
| --- | --- | --- |
| P1 | AI 只会用代码写地图 | 程序化脚本 + 硬编码坐标，三维空间理解能力不足 |
| P2 | 想象与结果有出入 | 自然语言描述不清位置、尺度、朝向、层次、视线 |
| P3 | 不知道要什么颜色 | 说了「这是山、这是树」也不知道具体色彩 / 材质 / 风格 |
| P4 | 只会堆几何体 | 不知道场景「具体长什么样」，只能方块圆柱平面堆叠 |

这四个痛点是否成立、「中间层」方案是否可行，见调研报告。
